手动部署必须操作项

1. 安装依赖
   在项目目录运行：
   npm install
   然后运行 npm run build 验证。

2. 创建 Cloudflare D1 数据库
   在 Cloudflare Dashboard 创建 D1 数据库，例如：blogdb。
   不要把真实 database_id 提交到 GitHub。

3. 配置 Cloudflare Pages 绑定
   在 Pages 项目 Settings -> Functions -> D1 database bindings 中新增绑定：
   变量名：DB
   数据库：blogdb

4. 配置环境变量
   在 Pages 项目 Settings -> Environment variables 中新增：
   JWT_SECRET=一段足够长的随机字符串
   ADMIN_PASSWORD=后台登录密码，可后续直接在 Cloudflare 中修改

5. 推送数据库迁移
   如果用 wrangler CLI 推送迁移，在本地 wrangler.toml 末尾临时追加 D1 配置：
   [[d1_databases]]
   binding = "DB"
   database_name = "blogdb"
   database_id = "你的 D1 database_id"
   migrations_dir = "drizzle"

   然后运行：
   npx wrangler d1 migrations apply blogdb --remote

   如果不想在本地配置 database_id，也可以直接在 Cloudflare D1 控制台执行 drizzle 目录里的 SQL。

6. 后台登录方式
   访问 /login，只输入 ADMIN_PASSWORD 对应的后台密码即可登录。
   后续改密码只需修改 Cloudflare Pages 环境变量 ADMIN_PASSWORD 并重新部署。

7. 部署到 Cloudflare Pages
   将代码推送到 GitHub，并在 Cloudflare Pages 连接该仓库。
   构建命令：npm run build
   输出目录：dist-pages
   根目录：留空
   项目是 SSR，dist-pages 中会生成 _worker.js，Pages 必须使用这个目录而不是 dist。

8. 安全开关
   部署后在 Cloudflare Dashboard 按需开启 Bots 保护和基础 WAF。
