这个站点的长期目标之一，是让内容逐步覆盖服务器和工具维护成本。

但早期不适合一上来就挂广告。

## 为什么 AdSense 不适合太早做

早期流量小，广告收益有限，还可能影响阅读体验。

更重要的是，如果为了广告去堆低质量内容，会伤害博客最重要的东西：可信度。

## 更现实的顺序

### 1. 真实教程

先写能解决问题的教程，比如：

- Cloudflare Pages 部署 Astro
- VPS 初始化和安全加固
- n8n 自部署和备份
- MCP 工具链配置

### 2. 合规推荐

当文章里确实用到某个服务，可以放官方 referral 或 affiliate。

原则：

- 必须真实使用或明确说明适用场景
- 不夸大收益
- 不诱导点击
- 有赞助或联盟关系就披露

### 3. 模板和服务

当教程沉淀足够多，可以整理成：

- n8n workflow 模板包
- 服务器初始化脚本
- AstroPaper 中文启动包
- 部署检查清单

这些比早期广告更贴近用户需求。

## 第一阶段指标

先不看收入，先看内容资产：

- 20 篇长期搜索文章
- 每篇有明确关键词
- 每篇至少解决一个具体问题
- 每月复查旧文和链接

有搜索入口以后，再评估变现方式。
