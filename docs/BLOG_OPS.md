# 博客运营说明

## 站点定位

中文个人开发者实战手册：AI 自动化、自托管运维、低成本独立博客。

## 栏目

- `ai-automation`：n8n、MCP、Agent 工作流
- `self-hosting`：VPS、Cloudflare、Docker、备份、安全
- `astro-blog`：AstroPaper、SEO、独立博客建设
- `income-log`：成本账、变现复盘、服务器维护成本

## 发文节奏建议

- 每周 1 篇深度教程，或 2 篇短教程。
- 每月更新 5 篇旧文，检查版本、价格、链接是否过期。
- 联盟/赞助内容必须披露，链接按需使用 `rel="sponsored nofollow"`。

## 长期子 Agent 建议

需要，但不建议全自动发布。推荐职责：

1. 每周选题和关键词研究
2. 生成草稿和检查清单
3. 技术验证、链接检查、SEO 检查
4. 提交 PR 或草稿，最终由人审核合并

## 首阶段目标

先做 20 篇长期搜索型实战文章，建立可信度和入口，再考虑广告或赞助。

## 每日自动化发布计划

- 09:00（北京时间）：发布《GitHub每日热点与AI资讯速览》
  - GitHub 升星最快前 5 个项目
  - AI 最新/最热资讯 3 条
- 16:00（北京时间）：发布《普通人可用AI工具速览》
  - AI 生图、AI 生视频、免费/低成本模型 API、普通人可直接用的工具与方法，共 5 条

### 自动发布门禁

1. `blog-agent` 负责搜集、交叉验证、写初稿、自审和润色。
2. `blog-agent` 必须请求 `main` agent 二审。
3. 只有二审返回 `APPROVED` 才能改成 `draft: false` 并 push。
4. 如果构建、审核或来源验证失败，保留草稿，不发布。
5. 每个阶段更新 `docs/AUTOMATION_STATUS.md`，作为长任务心跳。
